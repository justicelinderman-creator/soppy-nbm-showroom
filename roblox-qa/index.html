SHOW THE REPORT, NOT JUST A PROMISE

HOW A TEST WORKS

01 / Permission

Agree the game/version, test role, device, scenarios and delivery timing. Never request passwords, account cookies or private project files in the first message.

02 / Reproduction

Run the approved test. Record observable behavior, steps, context and screenshots only where permitted. No artificial or invented issues.

03 / Handoff

Supply a reviewed issue report. Distinguish verified failures from suspected problems and untested features; confirm agreed payment independently.
