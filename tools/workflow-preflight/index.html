What this review covers
Included
JSON parsing, basic node structure, duplicate names, connection source and target names, disabled nodes, credential-reference presence, and the exported HTTP Request retry flag.
Outside its scope
Live execution, secret scanning, credential validity, parameter and expression correctness, node versions or installed packages, port compatibility, reachability, service limits, and production or security certification.
Private by design
Nothing is uploaded or stored by this tool. The report omits raw node names, unknown type strings, credential identifiers, parameters, URLs, headers, code, expressions, and execution data. Clear the tab when finished.
Supports one editor-export JSON object with a nodes array. Batch arrays and .n8np packages are unsupported. Processing stops above 5 MiB, 2,000 nodes, 20,000 connection entries, or 50,000 connection containers; partial reviews are labeled. No findings does not mean a workflow will run correctly.
