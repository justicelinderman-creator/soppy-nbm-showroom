    What gets checked?

    Potential invisible obstacles

    Parts with explicitly saved high transparency and enabled collisions. Useful to investigate; invisible hitboxes may be intentional.

    Large loose geometry

    Large parts explicitly marked unanchored. These are physics-review candidates, not automatically wrong.

    Interaction and effects

    Enabled prompts with a zero or negative activation distance, high-rate particle emitters, and unusually long-range active lights.

    Read-only scene composition

    Instance and script-object counts. An exported XML file is a static snapshot, so live game memory and actual FPS are outside scope.

    How do I export the right file?

    In Roblox Studio, use File → Save to File and select the XML-based .rbxlx format, or export a model in XML .rbxmx format. A binary .rbxl or .rbxm won't work. Test with a disposable copy; exporting a file doesn't publish your game.

    Does Cosie upload or keep my game?

    No. This page contains no network requests or upload endpoints. Your browser reads your selected file locally and produces an in-memory report. No script contents are inspected, displayed or included in the export. Closing or refreshing the page clears the report. The optional JSON export is downloaded to your own device.

    Will this actually optimize my game?

    Not automatically. It identifies a few configuration patterns worth looking at. Roblox's built-in Scene Analysis and real-device profiling remain essential for performance work.
